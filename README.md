# DevFolio - Developer Portfolio

A responsive personal developer portfolio showcasing projects and contact links. Built using semantic HTML5, CSS Grid, Flexbox, and media queries.

## Live Demo
- **Live Site:** https://ishaatech.github.io/devfolio/
- **Repository:** https://github.com/ishaatech/devfolio

## Features
- Semantic structure (`<header>`, `<main>`, `<section>`, `<footer>`)
- Responsive design with CSS Grid and Flexbox
- Styled using CSS custom properties (variables)
- Deployed on GitHub Pages
